PROJECT OVERVIEW
----------------
Website: Vaalpenskraal Game Reserve - Luxury Safari & Hunting Experience
Location: Thabazimbi, Limpopo, South Africa (Waterberg Biosphere)
Target Audience: International luxury travelers, ethical hunters, conservation enthusiasts
Design Philosophy: "Iron Mountain" - Immersive Realism, Cinematic Luxury
Framework: Next.js 16.0.10 (App Router) with TypeScript
Repository: https://github.com/Franksmittt/vpk.git

================================================================================
1. DESIGN PHILOSOPHY & AESTHETIC
================================================================================

Core Aesthetic: "Iron Mountain" - Immersive Realism
----------------------------------------------------
- Cinematic, editorial approach that transports clients to the Waterberg Biosphere
- Rejects clichéd "safari brochure" aesthetic
- Sophisticated, dark luxury experience
- Feels like a high-end travel magazine rather than traditional hunting lodge website
- No blood imagery - clean, respectful presentation

Design Pillars:
1. Quiet Luxury - Understated elegance over flashy displays
2. Cinematic Verité - Film-like quality, atmospheric storytelling
3. Radical Transparency - Honest, direct communication about conservation and ethics
4. Technical Authority - Precision in ballistics, logistics, and species knowledge
5. Emotional Connection - Balancing the primal hunt with world-class luxury

================================================================================
2. COLOR PALETTE
================================================================================

PRIMARY COLORS (The Modern Heritage Palette)
--------------------------------------------
- Deep Olive (#2B3D26) - Primary color, signals authority, camouflage, nature
- Canvas Cream (#EFEBD6) - Secondary, replaces stark white, reduces glare, evokes tented camps
- Burnished Copper (#B87333) - Metallic accent for luxury, connects to "bullet/brass" aesthetic (also "clay")
- Signal Orange (#D65A31) - High visibility for conversion, refined nod to "Safety Orange"
- Espresso (#231F20) - Warm alternative to black, body text, dark mode backgrounds (also "charcoal")

BUSHVELD SPECTRUM COLORS (Authentic African Colors)
---------------------------------------------------
- Bushveld Soil (#894e34) - Oxidised iron-rich earth, grounding, warmth (also "soil")
- Acacia Bark (#543939) - Dark hardwood trunks, stability, ruggedness
- Winter Sky (#537285) - Mid-day horizon haze, expansive, calming
- Dried Grass (#9a7e49) - Dormant savannah grass, natural, seasonal
- Sunset Gold (#c98455) - Golden hour light, luxury, warmth, nostalgia (also "champagne")

LEGACY COLOR MAPPINGS (Backward Compatibility)
-----------------------------------------------
- charcoal → espresso (#231F20)
- sand → canvas-cream (#EFEBD6)
- clay → burnished-copper (#B87333)
- soil → bushveld-soil (#894e34)
- cream → canvas-cream (#EFEBD6)
- champagne → sunset-gold (#c98455)

TEXT COLORS
-----------
- Canvas Cream (#EFEBD6) - Primary text on dark backgrounds (headings, important text)
- White/White Opacity - Used for body text on dark backgrounds (white/80, white/70, white/60)
- Silver/Opacity - Secondary text (silver/80, silver/70, silver/60)
- Sunset Gold/Champagne - Accent text, highlights, CTAs

COLOR USAGE RULES
-----------------
- Never use pure white (#FFFFFF) - always use Canvas Cream or white with opacity
- Never use pure black (#000000) - always use Espresso or dark variants
- Accent colors should never exceed 20% of any viewport
- Gradients should be subtle, using earth tones only
- All contrast ratios meet WCAG AA standards (4.5:1 for text)

5. VISUAL EFFECTS & STYLING
================================================================================

GLASSMORPHISM (Frosted Glass Effect)
-------------------------------------
- Background: rgba(35, 31, 32, 0.4-0.6) - Semi-transparent espresso
- Backdrop Filter: blur(10px-12px) - Creates frosted glass effect
- Border: 1px solid rgba(255, 255, 255, 0.1) - Subtle white border
- Border Radius: 12px - Rounded corners
- Used in: Header, cards, booking widget, trust badges, modal overlays

GRADIENTS
---------
- Background gradients: linear-gradient(to bottom, rgba(35, 31, 32, 1) to rgba(35, 31, 32, 0.95))
- Hero overlays: bg-gradient-to-b from-charcoal/60 via-charcoal/40 to-transparent
- Multi-layer gradients: Combined gradients for depth (soil/clay/charcoal combinations)
- Image overlays: bg-black/20 to bg-black/40 - Dark overlays on images

SHADOWS & DEPTH
---------------
- Text shadows: 0 2px 8px rgba(0,0,0,0.5) to 0 4px 16px rgba(0,0,0,0.6)
- Box shadows: Minimal, used sparingly
- Depth created through: Layering, opacity, backdrop blur, gradient overlays

ANIMATIONS
----------
- Scroll fade: Elements fade in as user scrolls (Intersection Observer API)
- Hover effects: Scale transforms (scale-[1.02] to scale-110), opacity changes, border color transitions
- Page transitions: Smooth fade-in animations
- Auto-rotate: Species showcase auto-rotates every 4 seconds
- Float animation: Subtle floating effect for decorative elements (6s ease-in-out infinite)
- Transition duration: 300ms (fast), 500ms (standard), 700ms (smooth)

INTERSECTION OBSERVER SETTINGS
-------------------------------
- Threshold: 0.15 (15% visible triggers animation)
- Root margin: "0px 0px -50px 0px" (triggers slightly before element enters viewport)
- Applied to: All scroll-fade elements, section refs
